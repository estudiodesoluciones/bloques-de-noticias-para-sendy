# Historial

## 1.0.0 — 2026-10-30

- Selección de las últimas 1–100 noticias públicas, filtros por texto, categorías y fechas inclusivas.
- Selección individual o de todo el listado mostrado y cambio de orden.
- Resúmenes configurables, imagen destacada y enlaces a la noticia.
- Estilos configurables y diseño predeterminado guardado.
- Vista previa de escritorio/móvil y HTML completo o fragmento descargable.
- Conexión HTTPS a instalaciones remotas de Sendy, consulta de marcas y creación exclusiva de borradores.
- API key cifrada, permisos de administrador, nonces y protección ante doble creación.
- Autoría enlazada a Estudio de Soluciones en la ficha del plugin y el panel.

Validado con PHP 8.4.27, WordPress 7.1.4 y la instalación de Sendy 7. La API real creó el borrador de prueba 121 sin envío, programación ni listas. Las pruebas de lógica pasaron 32 comprobaciones; la interfaz se comprobó en Chrome con respuestas simuladas. La sesión autenticada del panel de producción no se automatizó.
